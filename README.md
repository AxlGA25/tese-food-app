
# 🍔 TESE Food App 

Aplicación multiplataforma diseñada para optimizar los tiempos de receso de los estudiantes del Tecnológico de Estudios Superiores de Ecatepec, permitiendo realizar pedidos anticipados a la cafetería escolar para evitar filas y agilizar la entrega de alimentos.

## 🚀 Características Principales
* **Menú Digital en Tiempo Real:** Catálogo de alimentos disponibles.
* **Sistema de Pedidos:** Carrito de compras con opciones de personalización.
* **Seguimiento de Estados:** Monitoreo del pedido (Recibido -> En Preparación -> Listo para recoger).
* **Gestión de Cafetería:** Panel administrativo para el control del flujo de órdenes.

## 🛠️ Stack Tecnológico
* **Frontend:** Flutter (iOS & Android)
* **Backend & Base de Datos:** Firebase (Firestore & Storage)
* **Control de Versiones:** Git / GitHub
